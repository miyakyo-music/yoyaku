# 練習室予約システム（GitHub Pages + GAS + スプレッドシート）

> 詳細な仕様は **[docs/仕様書.md](docs/仕様書.md)** を参照してください（変更のたびに更新）。

「りざぶ郎」の代替として開発した、サーバー不要・維持費ゼロ・広告なしの練習室予約Webアプリです。

- **予約表**: https://miyakyo-music.github.io/yoyaku/
- **管理画面**: https://miyakyo-music.github.io/yoyaku/admin.html

フロントエンドは GitHub Pages から配信し、データの読み書きは Google Apps Script（GAS）の JSON API で行います。GASで直接画面を配信する方式をとらないのは、Googleの複数アカウントログイン時のアクセス不具合や、iOS版Safariで `localStorage`（自動入力等）が機能しない制限を回避するためです。

## 管理画面・スプレッドシートの設定項目

以下の項目はすべて**管理画面**から変更でき、スプレッドシートを直接編集しても同じ結果になります。管理画面からの変更時は、入力値の検証（予約単位に合わない時刻の拒否など）や、影響を受ける既存予約の警告が行われます。

### 1.「設定」シート

| 項目 | 既定値 | 説明 |
| :--- | :--- | :--- |
| 予約表のタイトル | 練習室予約 | 画面上部のタイトル（例：宮教大音楽棟・練習室予約） |
| お知らせ | （空欄） | 画面上部に表示する連絡事項 |
| お知らせの種類 | 通常 | `通常`（青帯）／ `重要`（赤帯：休館など予約に直結する連絡） |
| 利用開始時刻 / 利用終了時刻 | 07:00 / 22:00 | 予約表の表示・受付時間帯 |
| 予約単位（分） | 5 | 60を割り切れる数 |
| 1回の最大予約時間（分） | 0（制限なし） | 管理者モードでは制限対象外 |
| 何日先まで予約できるか | 0（制限なし） | 管理者モードでは制限対象外 |
| 定休日（曜日） | （空欄） | 例：`日`、`土,日` |
| くり返し予約の最大回数 | 30 | 一括予約時の上限回数 |
| くり返し予約は管理者のみ | はい | `いいえ` にすると一般利用者も利用可能 |
| 閲覧パスワード | （空欄） | 設定すると予約表の閲覧自体にパスワードを要求 |
| 限定公開の部屋のパスワード | （空欄） | 「限定公開」の部屋を表示・予約するパスワード（6文字以上。空欄時は管理者のみ利用可） |

### 2.「部屋マスタ」シート

- **設定項目**: 表示順・部屋ID・部屋表示名・設備区分・予約制限・備考・特徴タグ（例：`大・GP`。「・」区切りでタグ表示）
- **予約制限の種類**:
  - `（空欄）`: 誰でも予約可
  - `管理者のみ`: 予約・変更・取消に管理用パスワードが必要
  - `限定公開`: 専用パスワード入力者および管理者のみに表示・予約可（演習室など）
  - `使用停止`: 予約不可（グレーアウト表示）
- **注意事項**:
  - `部屋ID` は予約データと紐づく内部識別子（追加時に自動採番・管理画面では非表示）のため、運用開始後は変更しないでください。
  - 今日以降の予約が残っている部屋は管理画面から削除できません。廃止する場合は「使用停止」に設定してください。

### 3.「休館・利用停止」シート

| 日付 | 部屋ID（空欄=全室） | 開始時刻（空欄=終日） | 終了時刻 | 理由 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-10-22 | | | | 入試 |
| 2026-10-08 | room_10 | | | ピアノ調律 |
| 2026-10-08 | | 21:00 | 22:00 | 全館清掃 |

対象時間帯は予約表に灰色の斜線と理由が表示され、新規予約ができなくなります（**既存の予約は自動取消されないため、必要に応じて個別に取消してください**）。

## 技術仕様・セキュリティの要点

- **API通信**: `fetch()` で GAS の WebアプリURLへ JSON（`{"action": 関数名, "params": {...}}`）を POST します。CORSのプリフライト（事前確認）を回避するため `Content-Type: text/plain` を使用し、Googleアカウントのログイン状態に干渉されないよう Cookie は送信しません。パスワード類はURLパラメータに含めません。
- **バージョン照合**: `web/api.js` と `gas/Code.gs` の `API_VERSION` が不一致の場合、画面下部に再読み込みを促すバナーを表示します。
- **排他制御（重複防止）**: 予約の登録・変更・取消時は `LockService.getScriptLock()`（最大10秒待機）を取得して台帳を再照合します。重複時は書き込みを中止して重複相手の時間・予約者名を返し、画面を最新状態に更新します。
- **本人確認とロックアウト**: 予約ごとに4桁の編集用パスワード（任意）を設定できます。同一予約で5回連続誤入力すると10分間ロックされます。
- **管理者権限**: 管理画面ログイン後に「予約表に戻る」と管理者モードになり、全予約をパスワードなしで変更・取消できます（一般画面の編集用パスワード欄に管理用パスワードを入力しても同様）。端末紛失やデータ消去で本人が取消できない場合も管理者が対応します。
- **データ保護・無害化**:
  - 編集用・閲覧用パスワードはサーバー側でのみ照合し、ブラウザへは送信しません。
  - スプレッドシートへの書き込みは「書式なしテキスト」として処理し、日時や先頭ゼロ（`0123`等）の自動変換を防ぎます。
  - 数式インジェクション対策として、先頭が `= + - @` で始まる入力は拒否します。
  - 取り消された予約は台帳から削除されますが、「操作ログ」シートに履歴が残ります。

## ローカル動作確認

`dev/serve.py` を起動すると `web/` が配信され、**ブラウザ上で本物の `gas/Code.gs` が動作します**。`dev/gas-stub.js` が `fetch()` をフックして `doPost` に渡し、スプレッドシートの動作もブラウザ内（ローカル保存）でエミュレートするため、本番環境には一切影響しません。

```bash
# ローカル起動
python3 dev/serve.py

# 同一Wi-Fi内のスマホ等から確認する場合（http://<MacのIPアドレス>:8765/ でアクセス）
python3 dev/serve.py --lan
```

- **予約表**: http://127.0.0.1:8765/
- **管理画面**: http://127.0.0.1:8765/admin.html （管理用パスワード: `admin123`）
- **データ初期化**: http://127.0.0.1:8765/?reset=1

## 対応環境・UI仕様

| 環境 | 対応状況 |
| :--- | :--- |
| iPhone / iPad（Safari・Chrome・Firefox） | iOS / iPadOS 15.4 以降で完全対応（12〜15.3 は代替ダイアログで動作） |
| Android（Chrome / Firefox） | 2022年以降のバージョンで対応 |
| PC（Chrome / Edge / Firefox / Safari） | 2022年以降のバージョンで対応 |
| Internet Explorer | 非対応 |

- **レスポンシブ対応**: 画面幅 600px 以下でスマホ用レイアウトに切り替わります（360px 未満の端末では縮小せず画面全体を横スクロール）。iOSでの入力時自動ズームを防ぐため、入力欄のフォントサイズは `16px` に固定しています。
- **時間軸のズーム機能**: 時間軸の標準幅は1時間あたり PC 96px / スマホ 76px（広い画面では右端まで拡張）です。ピンチ操作（PCは Ctrl＋ホイールまたはトラックパッドのピンチ）で1日全体が収まる幅まで縮小でき、設定幅は端末に記憶されます（左上の「幅をリセット」で初期化可能。カレンダー表示は最小48px/日）。

## 運用上の注意事項

- **`localStorage` のスコープ**: 自動入力・自分の予約・表示設定等は端末・ブラウザごとに保存されます。別端末からは参照できません（予約の変更・取消自体は編集用パスワードで可能）。また、オリジン（`miyakyo-music.github.io`）単位で領域を共有するため、同一GitHub組織の別リポジトリでPagesを公開する場合はキーの競合に注意してください。
- **本人確認の限界**: 予約者情報は自己申告制です。厳密ななりすまし対策が必要になった場合は、Googleログイン必須（組織内限定アクセス）への仕様変更を検討してください。
