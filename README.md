# 練習室予約システム（GAS + スプレッドシート）

「りざぶ郎」の置き換えとして作った、サーバー不要・維持費ゼロ・広告なしの練習室予約Webアプリです。

| ファイル | 役割 |
| :--- | :--- |
| `gas/Code.gs` | サーバー側（予約の取得・登録・変更・取消、排他制御、管理メニュー） |
| `gas/Index.html` | 予約表の画面。CSS/JSもこの1ファイルに同梱（外部ライブラリなし） |
| `gas/Admin.html` | 管理画面（練習室・利用時間・休館日・パスワードの設定） |
| `gas/appsscript.json` | マニフェスト（タイムゾーン・公開設定） |
| `dev/` | ローカル動作確認用（本番には不要） |
| `docs/GASデプロイ手順.md` | Google Apps Script への導入・更新手順 |
| `docs/運用・引き継ぎマニュアル.md` | 年度切り替え・卒業時の引き継ぎ手順（A4 1枚） |

## りざぶ郎との機能対応

| りざぶ郎 | 本システム |
| :--- | :--- |
| 一覧（全部屋 × 時刻） | 「一覧」タブ。部屋名列・時刻行は固定表示。現在時刻の赤線、過去は灰色 |
| アイテム別 | 「部屋別」タブ。1部屋の7日分を並べて表示 |
| カレンダー | 「カレンダー」タブ。月表示（部屋を選ぶとその部屋の予約、全室なら件数） |
| 背景をドラッグして予約／指でなぞる | PC: クリックまたはドラッグ。スマホ: タップ、または長押ししてからなぞる |
| 新規予約ボタン | 「＋新規予約」から部屋・日付・時刻を指定して予約 |
| 予約の変更・削除 | 予約をタップ →「変更」（日付・部屋・時間・氏名・備考）／「取消」。暗証番号で本人確認 |
| 連続／一括登録 | くり返し予約（毎週・隔週・毎日）と複数部屋の同時予約（練習室6の全台を押さえる など）。組み合わせ可（最大100件）。予約できない分を除いて登録でき、「この日以降をまとめて取消」も可 |
| 予約時間の単位 | **5分単位**（「設定」シートで 1〜60分に変更可） |
| 予約時の入力項目 | 学籍番号/所属・氏名・備考・暗証番号（任意。設定しない予約は誰でも変更・取消できる） |
| 部屋の特徴表示 | 「大」「GP」「電子P.1」などを部屋名の下にタグで表示。部屋の選択肢には「練習室16（大・GP）」の形で表示 |
| 更新 | 「更新」ボタン＋60秒ごとの自動更新 |
| ログインパスワード | 「設定」シートの「閲覧パスワード」。設定すると閲覧・予約にパスワードが必要（端末に記憶） |
| 管理者のみ予約可能なアイテム | 「部屋マスタ」の予約制限に「管理者のみ」 |
| 休暇（休業日）設定 | 「設定」シートの定休日（曜日）＋「休館・利用停止」シート（日付・部屋・時間帯を指定） |
| 管理画面 | 予約表右上の「管理」（または URL末尾に `?page=admin`）。管理用パスワードでログインし、練習室の追加・削除・編集・並べ替え、利用時間・予約単位・各種制限、休館・利用停止、管理用パスワードを変更できる。スプレッドシートを直接編集してもよい |
| サブグループ | 「設備区分」による絞り込み |
| ― | この端末で作った予約の一覧（自分の予約）、予約者の自動入力、操作ログ（取消後も記録が残る） |

りざぶ郎の「登録後に管理者の承認が必要」「予約者本人と管理者のみ変更可（有料）」は未実装です。後者は暗証番号方式で実質的に満たしています。印刷機能は利用実態がないため設けていません。

## 管理者が変更できること

以下はすべて**管理画面**から変更できます（スプレッドシートの各シートを直接編集しても同じ結果になります）。管理画面では、入力値の検証（予約単位に合わない時刻の拒否など）や、変更によって影響を受ける既存予約の警告も行います。

### 「設定」シート

| 項目 | 既定値 | 説明 |
| :--- | :--- | :--- |
| 予約表のタイトル | 練習室予約 | 画面上部の名前（例：宮教大音楽棟・練習室予約） |
| お知らせ | （空欄） | 画面上部に表示する連絡事項 |
| 利用開始時刻 / 利用終了時刻 | 07:00 / 22:00 | |
| 予約単位（分） | 5 | 60を割り切れる数 |
| 1回の最大予約時間（分） | 0（制限なし） | 管理者は制限を受けない |
| 何日先まで予約できるか | 0（制限なし） | 管理者は制限を受けない |
| 定休日（曜日） | （空欄） | 例：`日`、`土,日` |
| くり返し予約の最大回数 | 30 | |
| くり返し予約は管理者のみ | はい | `いいえ` にすると誰でも使える |
| 閲覧パスワード | （空欄） | 設定すると予約表の閲覧にパスワードが必要 |

### 「部屋マスタ」シート

- 表示順・部屋ID・部屋表示名・設備区分・予約制限・備考・特徴タグ（例：`大・GP`。「・」区切りでタグとして表示）
- **予約制限**: 空欄 = 誰でも予約可 ／ `管理者のみ` = 予約・変更・取消に管理用パスワードが必要 ／ `使用停止` = 予約不可（灰色表示）
- 部屋IDは予約データと結びついているので、一度使い始めたら変更しないこと（部屋IDはシステム内部の番号で、管理画面には表示されません。追加時に自動で振られます）
- 今日以降の予約が残っている部屋は削除できません（管理画面で削除しようとすると止まります）。「使用停止」にしてください

### 「休館・利用停止」シート

| 日付 | 部屋ID（空欄=全室） | 開始時刻（空欄=終日） | 終了時刻 | 理由 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-10-22 | | | | 入試 |
| 2026-10-08 | room_10 | | | ピアノ調律 |
| 2026-10-08 | | 21:00 | 22:00 | 全館清掃 |

予約表に灰色の斜線で理由が表示され、その時間帯は予約できなくなります（既に入っている予約は自動では消えないので、必要なら個別に取り消してください）。

## 仕様の要点

- **重複防止**: `LockService.getScriptLock()`（最大10秒待機）を取ってから台帳を再照合し、重なりがあれば書き込まずに「すでに存在する予約と時間が重複しています（重なった予約の時間・予約者）」を返し、画面の予約表を最新の状態に更新します。変更・取消も同じロックの中で行います。
- **本人確認**: 予約ごとの4桁暗証番号（任意）。設定しなかった予約は誰でも変更・取消できます（予約画面にもその旨を表示）。同じ予約に5回続けて間違えると10分間操作不可。
- **管理者**: 管理画面にログインしたまま「予約表に戻る」と「管理者モード」になり、暗証番号の有無にかかわらず、どの予約も変更・取消できます（暗証番号欄に管理用パスワードを入れても同じ）。端末を替えた・localStorage が消えたなどで本人が取り消せない予約は、管理者が対応します。
- **暗証番号・閲覧パスワードはブラウザへ送信しません。**
- 台帳への書き込みは「書式なしテキスト」で行い、日付・時刻・`0123` のような暗証番号の自動変換を防ぎます。先頭が `= + - @` の入力は拒否します（数式インジェクション対策）。
- 取り消した予約は台帳から削除されますが、「操作ログ」シートに誰がいつ何をしたかが残ります。

## 動作確認（ローカル）

`dev/serve.py` は、**本物の `gas/Code.gs` をブラウザ上で動かし**（スプレッドシート等は `dev/gas-stub.js` が模擬し、データはブラウザに保存）、`gas/Index.html` を表示します。サーバー側の処理もそのまま試せます。管理画面は http://127.0.0.1:8765/?page=admin 、管理用パスワードは `admin123`。

```bash
python3 dev/serve.py
```

同じWi-Fiにつないだスマホから確認するときは `python3 dev/serve.py --lan` で起動し、`http://<このMacのIPアドレス>:8765/` を開きます。

ブラウザで http://127.0.0.1:8765/ を開きます。データを初期化するには、ブラウザのコンソールで `gasStub.reset()` を実行します。

## 対応ブラウザ・端末

| 環境 | 対応 |
| :--- | :--- |
| iPhone / iPad（Safari・Chrome・Firefox。iOSではいずれもSafariと同じエンジン） | iOS / iPadOS 15.4 以降で完全対応。12〜15.3 は代替のダイアログ表示で動作 |
| Android（Chrome / Firefox） | 2022年以降のバージョンで対応 |
| PC（Chrome / Edge / Firefox / Safari） | 2022年以降のバージョンで対応 |
| Internet Explorer | 非対応（Google Apps Script 自体が非対応） |

- 画面幅 600px 以下ではスマホ用の配置に切り替えます。画面幅が 360px 未満の端末では、縮めずに画面全体を横スクロールします。
- 予約表の時間軸は1時間あたり一定の幅（PC 96px／スマホ 76px）で表示し、画面に入りきらない分は横スクロールします。カレンダーは1日あたり48px未満にはしません。
- 入力欄の文字サイズは16px（iPhoneで入力時に画面が拡大されるのを防ぐため）。
- GASのウェブアプリでは、画面上部にGoogleによる「このアプリケーションは Google ではなく、別のユーザーによって作成されたものです」という帯が表示されます（全員に公開する場合は消せません）。

## 注意事項

- localStorage は「端末・ブラウザごと」の保存です。別の端末では自動入力・薄青表示・「自分の予約」は効きません（予約・変更・取消自体は暗証番号で可能）。
- 本システムの予約者情報は自己申告です。なりすまし対策が必要になった場合は、Googleログイン必須（アクセス: 組織内）への切り替えを検討してください。
