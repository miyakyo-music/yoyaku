# 練習室予約システム（GitHub Pages + GAS + スプレッドシート）

「りざぶ郎」の置き換えとして作った、サーバー不要・維持費ゼロ・広告なしの練習室予約Webアプリです。

- 予約表: https://miyakyo-music.github.io/yoyaku/
- 管理画面: https://miyakyo-music.github.io/yoyaku/admin.html

画面は GitHub Pages から配信し、データの読み書きは Google Apps Script（GAS）の API が行います（GAS は JSON だけを返す）。GAS の画面を直接開く方式だと、Google の複数アカウントでログインしているときに開けなかったり、iPhone の Safari で端末への保存（自動入力など）が効かなかったりするためです。

## 管理者が変更できること

以下はすべて**管理画面**から変更できます（スプレッドシートの各シートを直接編集しても同じ結果になります）。管理画面では、入力値の検証（予約単位に合わない時刻の拒否など）や、変更によって影響を受ける既存予約の警告も行います。

| 項目 | 既定値 | 説明 |
| :--- | :--- | :--- |
| 予約表のタイトル | 練習室予約 | 画面上部の名前（例：宮教大音楽棟・練習室予約） |
| お知らせ | （空欄） | 画面上部に表示する連絡事項 |
| 利用開始時刻 / 利用終了時刻 | 07:00 / 22:00 | |
| 予約単位（分） | 5 | 60を割り切れる数 |
| 1回の最大予約時間（分） | 0（制限なし） | 管理者は制限を受けない |
| 何日先まで予約できるか | 0（制限なし） | 管理者は制限を受けない |
| 定休日（曜日） | （空欄） | 例：`日`、`土,日` |
| くり返し予約の最大回数 | 30 | |
| くり返し予約は管理者のみ | はい | `いいえ` にすると誰でも使える |
| 閲覧パスワード | （空欄） | 設定すると予約表の閲覧にパスワードが必要 |
| 限定公開の部屋のパスワード | （空欄） | 予約制限「限定公開」の部屋を表示・予約するためのパスワード（6文字以上）。空欄なら管理者以外は使えない |

### 「部屋マスタ」シート

- 表示順・部屋ID・部屋表示名・設備区分・予約制限・備考・特徴タグ（例：`大・GP`。「・」区切りでタグとして表示）
- **予約制限**: 空欄 = 誰でも予約可 ／ `管理者のみ` = 予約・変更・取消に管理用パスワードが必要 ／ `限定公開` = 限定公開の部屋のパスワードを入れた人だけに表示・予約可（演習室など） ／ `使用停止` = 予約不可（灰色表示）
- 部屋IDは予約データと結びついているので、一度使い始めたら変更しないこと（部屋IDはシステム内部の番号で、管理画面には表示されません。追加時に自動で振られます）
- 今日以降の予約が残っている部屋は削除できません（管理画面で削除しようとすると止まります）。「使用停止」にしてください

### 「休館・利用停止」シート

| 日付 | 部屋ID（空欄=全室） | 開始時刻（空欄=終日） | 終了時刻 | 理由 |
| :--- | :--- | :--- | :--- | :--- |
| 2026-10-22 | | | | 入試 |
| 2026-10-08 | room_10 | | | ピアノ調律 |
| 2026-10-08 | | 21:00 | 22:00 | 全館清掃 |

予約表に灰色の斜線で理由が表示され、その時間帯は予約できなくなります（既に入っている予約は自動では消えないので、必要なら個別に取り消してください）。

## 仕様の要点

- **通信**: 画面は `fetch()` で GAS のウェブアプリ URL に POST する（本文は `{"action": 関数名, "params": {...}}` の JSON）。CORS の事前確認を避けるため `Content-Type: text/plain`、Google のログイン状態に左右されないよう Cookie は送らない。GAS 側は `doPost` で `API` に登録した関数だけを実行し、`ContentService` で JSON を返す。パスワード類は URL に載せない。
- **版の照合**: `web/api.js` と `gas/Code.gs` の `API_VERSION` が違うと、画面の下に再読み込みを促す帯を出す。

- **重複防止**: `LockService.getScriptLock()`（最大10秒待機）を取ってから台帳を再照合し、重なりがあれば書き込まずに「すでに存在する予約と時間が重複しています（重なった予約の時間・予約者）」を返し、画面の予約表を最新の状態に更新します。変更・取消も同じロックの中で行います。
- **本人確認**: 予約ごとの4桁の編集用パスワード（任意）。設定しなかった予約は誰でも変更・取消できます（予約画面にもその旨を表示）。同じ予約に5回続けて間違えると10分間操作不可。
- **管理者**: 管理画面にログインしたまま「予約表に戻る」と「管理者モード」になり、編集用パスワードの有無にかかわらず、どの予約も変更・取消できます（編集用パスワード欄に管理用パスワードを入れても同じ）。端末を替えた・localStorage が消えたなどで本人が取り消せない予約は、管理者が対応します。
- **編集用パスワード・閲覧パスワードはブラウザへ送信しません。**
- 台帳への書き込みは「書式なしテキスト」で行い、日付・時刻・`0123` のような編集用パスワードの自動変換を防ぎます。先頭が `= + - @` の入力は拒否します（数式インジェクション対策）。
- 取り消した予約は台帳から削除されますが、「操作ログ」シートに誰がいつ何をしたかが残ります。

## 動作確認（ローカル）

`dev/serve.py` は `web/` の画面を配信し、**本物の `gas/Code.gs` をブラウザ上で動かします**。GAS への `fetch()` を `dev/gas-stub.js` が横取りして `doPost` に渡し、スプレッドシート等も模擬します（データはブラウザに保存）。本番の GAS には一切通信しません。管理画面は http://127.0.0.1:8765/admin.html 、管理用パスワードは `admin123`。

```bash
python3 dev/serve.py
```

同じWi-Fiにつないだスマホから確認するときは `python3 dev/serve.py --lan` で起動し、`http://<このMacのIPアドレス>:8765/` を開きます。

ブラウザで http://127.0.0.1:8765/ を開きます。データを初期化するには http://127.0.0.1:8765/?reset=1 を開きます。

## 対応ブラウザ・端末

| 環境 | 対応 |
| :--- | :--- |
| iPhone / iPad（Safari・Chrome・Firefox。iOSではいずれもSafariと同じエンジン） | iOS / iPadOS 15.4 以降で完全対応。12〜15.3 は代替のダイアログ表示で動作 |
| Android（Chrome / Firefox） | 2022年以降のバージョンで対応 |
| PC（Chrome / Edge / Firefox / Safari） | 2022年以降のバージョンで対応 |
| Internet Explorer | 非対応 |

- 画面幅 600px 以下ではスマホ用の配置に切り替えます。画面幅が 360px 未満の端末では、縮めずに画面全体を横スクロールします。
- 予約表の時間軸は1時間あたり一定の幅（PC 96px／スマホ 76px。広い画面では右端まで広げる）で表示し、画面に入りきらない分は横スクロールします。2本指のピンチ（PC は Ctrl＋ホイール、トラックパッドのピンチ）で時間軸の幅を変えられ、1日全体が画面に収まる幅まで縮められます。変えた幅は端末に記憶し、幅を変えている間は予約表の左上（「部屋 ＼ 時刻」の所）に出る「幅をリセット」で戻せます。カレンダーは1日あたり48px未満にはしません。
- 入力欄の文字サイズは16px（iPhoneで入力時に画面が拡大されるのを防ぐため）。

## 注意事項

- localStorage は「端末・ブラウザごと」の保存です（`miyakyo-music.github.io` に対して保存されるので、同じ組織で別のサイトを公開すると保存領域を共有する点に注意）。別の端末では自動入力・薄青表示・「自分の予約」は効きません（予約・変更・取消自体は編集用パスワードで可能）。
- 本システムの予約者情報は自己申告です。なりすまし対策が必要になった場合は、Googleログイン必須（アクセス: 組織内）への切り替えを検討してください。
