# Google Apps Script へのデプロイ手順

練習室予約システムを Google Apps Script（GAS）のウェブアプリとして公開する手順です。所要時間は30分程度。
作業には、共有ドライブにファイルを作成できる大学の Google アカウントを使います。

## 準備するファイル

このリポジトリの `gas/` フォルダにある4つのファイルを使います（`dev/` フォルダは手元での動作確認用なので不要）。

| ファイル | GASエディタ上の名前 | 内容 |
| :--- | :--- | :--- |
| `gas/Code.gs` | `コード.gs`（または `Code.gs`） | サーバー側の処理 |
| `gas/Index.html` | `Index` | 予約表の画面 |
| `gas/Admin.html` | `Admin` | 管理画面 |
| `gas/appsscript.json` | `appsscript.json` | タイムゾーン・公開設定 |

> HTMLファイルの名前は **`Index` と `Admin`（大文字始まり、拡張子なし）** にしてください。名前が違うと画面が表示されません。

---

## 1. スプレッドシートを作る

1. Google ドライブで、**学科または専任教員の「共有ドライブ」** を開く。
2. 「新規 > Google スプレッドシート」で空のスプレッドシートを作る。
3. 名前を付ける（例：`練習室予約システム`）。

> 個人の「マイドライブ」には作らないでください。作成者が卒業してアカウントが消えると、データごと消えます。

## 2. コードを貼り付ける

1. スプレッドシートのメニュー **「拡張機能 > Apps Script」** を開く。
2. 左上のプロジェクト名（「無題のプロジェクト」）を押し、名前を付ける（例：`練習室予約`）。
3. **Code.gs**：最初からある `コード.gs` の中身をすべて消し、`gas/Code.gs` の内容を貼り付ける。
4. **Index**：左の「ファイル」の **＋ > HTML** → 名前に `Index` と入力 → 中身をすべて消し、`gas/Index.html` の内容を貼り付ける。
5. **Admin**：同様に **＋ > HTML** → 名前 `Admin` → `gas/Admin.html` の内容を貼り付ける。
6. **appsscript.json**：
   1. 左の歯車「プロジェクトの設定」を開き、**「『appsscript.json』マニフェスト ファイルをエディタで表示する」** にチェックを入れる。
   2. 左の「エディタ」（`< >`）に戻ると `appsscript.json` が表示されるので、中身を `gas/appsscript.json` の内容に置き換える。
7. 上部の保存ボタン（フロッピーのアイコン）、または `Ctrl + S`（Mac は `⌘ + S`）で保存する。

## 3. 初期セットアップを実行する

1. エディタ上部の関数の選択欄で **`setup`** を選び、**「実行」** を押す。
2. 初回は権限の確認が出る：
   1. 「権限を確認」→ 自分のアカウントを選ぶ。
   2. 「このアプリは Google で確認されていません」と出た場合は、**「詳細」→「（プロジェクト名）（安全ではないページ）に移動」** を押す。（自分で作ったスクリプトなので問題ありません）
   3. 「許可」を押す。
3. 実行ログに「実行完了」と出たら、スプレッドシートに次のシートが作られています。

| シート | 内容 |
| :--- | :--- |
| 予約台帳 | 予約1件 = 1行 |
| 部屋マスタ | 練習室の一覧（初期値は現在のりざぶ郎と同じ30室） |
| 休館・利用停止 | 予約を受け付けない日時 |
| 設定 | 利用時間・予約単位・各種制限 |
| 操作ログ | 予約・変更・取消の記録 |

## 4. 管理用パスワードを設定する

1. スプレッドシートのタブに戻り、**ページを再読み込み**する。
2. メニューに **「予約システム」** が出るので、**「予約システム > 管理用パスワードを設定」** を選ぶ。
3. 6文字以上のパスワードを入力して OK。

> このパスワードで管理画面にログインし、すべての予約を変更・取消できます。管理者以外に教えないでください。

## 5. ウェブアプリとしてデプロイする

1. Apps Script エディタ右上の **「デプロイ > 新しいデプロイ」** を押す。
2. 「種類の選択」の歯車アイコンから **「ウェブアプリ」** を選ぶ。
3. 次のように設定する：

   | 項目 | 設定値 | 理由 |
   | :--- | :--- | :--- |
   | 説明 | 例：`初版` | 任意。後で版を見分けるため |
   | 次のユーザーとして実行 | **自分** | 利用者がスプレッドシートに直接アクセスせずに済むように |
   | アクセスできるユーザー | **全員** | 他大生・Googleにログインしていない人も使えるように |

4. **「デプロイ」** を押す（権限の確認が出たら、手順3と同じように許可する）。
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/……/exec`）をコピーする。

> 「アクセスできるユーザー」に「全員」が出ない場合は、大学の Google Workspace の管理者が外部公開を制限しています。情報システム担当に確認してください。

## 6. 動作確認

1. コピーした URL を開き、予約表が表示されることを確認する。
2. URL の末尾に `?page=admin` を付けて開き（予約表右上の「管理」からも可）、管理用パスワードでログインできることを確認する。
3. 管理画面で次を確認・修正する：
   - **練習室**：部屋名・特徴タグ（大・GP・UP など）・設備区分を実物と照合する（特に練習室21の表記）。
   - **利用時間・制限**：予約表のタイトル（例：宮教大音楽棟・練習室予約）、利用時間、予約単位など。
4. **Google にログインしていないブラウザ**（シークレットウィンドウなど）で URL を開き、予約できることを確認する。ログインを求められる場合は、手順5の「アクセスできるユーザー」が「全員」になっていません。
5. テスト用に入れた予約は、予約表から取り消しておく。

## 7. 利用者への案内

- 予約表の URL（`…/exec`）を、掲示物・QRコード・学科の案内ページなどで知らせる。
- 管理画面の URL（`…/exec?page=admin`）と管理用パスワードは、管理者だけに伝える。

## コードを修正したとき（URL を変えずに更新する）

1. Apps Script エディタで、変更したファイルの中身を新しい内容に貼り替えて保存する。
2. **「デプロイ > デプロイを管理」** を開く。
3. 公開中のデプロイを選び、右上の **鉛筆アイコン（編集）** を押す。
4. 「バージョン」で **「新バージョン」** を選び、**「デプロイ」** を押す。

> **「新しいデプロイ」は使わないでください。** URL が変わり、案内済みのURL・QRコードが使えなくなります。
> 保存しただけでは公開中の画面は変わりません。必ず上の手順で新バージョンを作ってください。

### 公開前に変更を試したいとき

「デプロイ > デプロイをテスト」で表示される URL（末尾が `/dev`）は、**保存済みの最新コード**で動きます。
編集権限を持つ人しか開けないので、利用者に影響を与えずに確認できます（データは本番と同じスプレッドシートを使うので、テスト予約は取り消しておくこと）。

---

## 担当者が交代するとき

ウェブアプリは **デプロイした人のアカウント** で動きます。前任者のアカウントが失効すると止まるので、卒業・異動の前に後任者が新しくデプロイし直してください。手順は [運用・引き継ぎマニュアル](運用・引き継ぎマニュアル.md) の「3. 卒業・担当交代時」にあります。

## よくあるトラブル

| 症状 | 原因と対処 |
| :--- | :--- |
| URL を開くと「Index という名前の HTML ファイルが見つかりません」といったエラーが出る | HTMLファイルの名前が `Index` / `Admin` になっていない（大文字・小文字も区別されます） |
| 予約表に「シート『予約台帳』が見つかりません」と出る | 手順3の `setup` を実行していない |
| メニュー「予約システム」が出ない | スプレッドシートを再読み込みする。それでも出ない場合は `setup` を一度実行する |
| 管理画面に「管理用パスワードが設定されていません」と出る | 手順4を行う |
| 他の人が開くと Google のログインを求められる | デプロイの「アクセスできるユーザー」が「全員」になっていない。デプロイを管理 → 編集で変更する |
| 修正したのに画面が変わらない | 新バージョンでデプロイしていない（上の「コードを修正したとき」を参照） |
| 画面上部に「このアプリケーションは Google ではなく…」という帯が出る | GAS のウェブアプリを公開すると必ず表示される Google の仕様です。消せません |
