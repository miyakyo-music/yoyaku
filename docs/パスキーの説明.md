# 管理画面のパスキー（Face ID / Touch ID）ログインについて

練習室予約システムの管理画面に、「パスキー」でのログインを加えました。安全性についてのご説明です。

## パスキーとは

パスワードの代わりに、スマートフォンやパソコンの **Face ID・Touch ID・画面ロックの解除** でログインする仕組みです。Apple・Google・Microsoft が共同で進めている業界標準（FIDO2 / WebAuthn）で、銀行・Google アカウント・政府のサービスなどでも使われています。

## よくあるご心配

**Q. 顔や指紋の情報が、サーバーに送られるのでは？**
送られません。顔や指紋の照合は、端末の中だけで行われます。システムに届くのは「本人確認が済んだ」という電子署名だけで、顔や指紋の情報はどこにも保存されません。

**Q. サーバーから情報が漏れたら、なりすまされるのでは？**
なりすましはできません。サーバーに置くのは「公開鍵」という、署名が正しいかを確かめるためだけの情報です。これが漏れても、ログインに使うことはできません（合い鍵にはなりません）。ログインに必要な「秘密の鍵」は、登録した端末の中から出ません。

**Q. 偽のサイトにだまされて入力してしまう心配は？**
パスキーは、登録したサイト（予約システムのアドレス）でしか使えないよう、端末が自動で確かめます。見た目をまねた偽サイトでは使えないため、パスワードを盗む詐欺（フィッシング）が効きません。

**Q. 端末をなくしたら？**
端末を拾った人は、Face ID・Touch ID・画面ロックを解除できなければ使えません。ほかの端末か管理用パスワードで管理画面に入り、なくした端末のパスキーを削除すれば、その端末では入れなくなります。

**Q. パスワードは使えなくなるのですか？**
今の管理用パスワードは、これまで通り使えます。パスキーは「使いたい人が使える、もう1つの入り口」です。

## このシステムでの仕組み

- パスキーの署名は、予約表の読み込みを速くするために使っている Cloudflare（高速キャッシュ）で確かめます。確かめられたら、12時間だけ有効な「ログインの印」を出します。
- 予約の正本（スプレッドシート）を扱う Google のサーバー（GAS）は、その印が本物かを、両者だけが知る合言葉で確かめてから処理します。
- パスキーの登録・削除は、管理者としてログインしている人だけができます。登録したパスキーは、管理画面で一覧を見て、いつでも削除できます。
- パスキーをやめると決めた場合は、設定を1か所変えるだけで、管理用パスワードだけの今まで通りの形に戻せます。

## まとめ

| | 管理用パスワード | パスキー |
| :--- | :--- | :--- |
| 盗み見・使い回しで漏れる | ありうる | ない（覚えたり入力したりしない） |
| 偽サイトでだまし取られる | ありうる | ない（本物のサイトでしか使えない） |
| サーバーから漏れたとき | なりすましに使われうる | 使えない（公開鍵だけ） |
| 顔・指紋の情報 | ― | 端末から出ない |
