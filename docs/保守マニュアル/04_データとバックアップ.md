# 04 データとバックアップ

対象: 管理者・システム担当者。

予約のデータはすべて Google スプレッドシート1つに保存されています。リポジトリ（GitHub）にはデータは入っていません。スプレッドシートは、管理画面の「データベース」ボタンから開けます（共有されている Google アカウントのみ）。

- スプレッドシートの置き場所: （要確認：共有ドライブ名・ファイル名）
- シートは、スプレッドシートのメニュー「予約システム > 初期セットアップ」（`setup`）で自動で作られます。何度実行しても既存のデータは消えません。

## 1. シートと列

**シート名と1行目の見出し、列の順番は変えないでください。** プログラムは列の位置で読み書きしています。シート名を変えると予約表が動かなくなります。

### 予約台帳（予約1件 = 1行）

| 列 | 見出し | 内容 |
| :--- | :--- | :--- |
| A | 予約ID | `res_` で始まる自動の番号 |
| B | 予約日 | `2026-10-09` の形 |
| C | 部屋ID | 部屋マスタの部屋ID（例: `room_16`） |
| D | 開始時刻 | `10:00` の形 |
| E | 終了時刻 | `12:00` の形 |
| F | 学籍番号/所属 | 任意（30文字以内） |
| G | 氏名・団体名 | 必須（50文字以内） |
| H | 編集用パスワード | 4桁の数字。空欄なら設定なし。**画面には返さないが、シートでは見える** |
| I | 作成日時 | `2026-10-09 08:00:00` の形 |
| J | まとめ予約ID | くり返し・複数部屋の予約で共通の `grp_` で始まる番号。単独の予約は空欄 |
| K | 備考 | 任意（100文字以内） |
| L | 更新日時 | 変更したときの日時 |

- 書き込みは「書式なしテキスト」で行い、日付・時刻・`0123` のような番号が自動で変換されないようにしています。手で入力するときも、日付は `2026-10-09`、時刻は `10:00` の形にしてください。
- 取り消した予約は、この表から行ごと削除されます（記録は操作ログに残ります）。

### 予約台帳_YYYY年度

- メニュー「予約システム > 前年度の予約をアーカイブ」で作られる、前年度の予約の保管用シート（列は予約台帳と同じ）。
- 予約表には表示されません。

### 部屋マスタ

| 列 | 見出し | 内容 |
| :--- | :--- | :--- |
| A | 表示順 | 予約表の並び順 |
| B | 部屋ID | `room_01` など。**予約データと結び付いているので変えない** |
| C | 部屋表示名 | 例: 練習室16 |
| D | 設備区分 | 絞り込み用。例: グランドピアノ |
| E | 予約制限 | 空欄／管理者のみ／限定公開／使用停止 |
| F | 備考 | |
| G | 特徴タグ | 例: `大・GP`（「・」区切り） |

- 初期セットアップでは、りざぶ郎の部屋構成に合わせた初期の部屋（練習室1〜26、練習室6と19は電子ピアノごとに分けたもの）が入ります。実際の設備に合わせて管理画面で直してください。

### 休館・利用停止

| 列 | 見出し | 内容 |
| :--- | :--- | :--- |
| A | 日付 | `2026-10-22` の形 |
| B | 部屋ID（空欄=全室） | |
| C | 開始時刻（空欄=終日） | |
| D | 終了時刻 | |
| E | 理由 | 予約表に表示される（50文字以内） |

### 設定

| 列 | 見出し | 内容 |
| :--- | :--- | :--- |
| A | 項目 | 項目名。**変えない** |
| B | 値 | 設定値 |
| C | 説明 | |

主な項目: 予約表のタイトル／お知らせ／お知らせの種類／利用開始時刻／利用終了時刻／予約単位（分）／1回の最大予約時間（分）／何日先まで予約できるか／定休日（曜日）／まとめて予約の最大件数／まとめて予約は管理者のみ／閲覧パスワード／限定公開の部屋のパスワード

- **「閲覧パスワード」「限定公開の部屋のパスワード」は、このシートにそのまま書かれています。** スプレッドシートを共有する相手は管理者に限ってください。
- 管理用パスワードはこのシートにはありません（GAS のスクリプトプロパティ `ADMIN_PASSWORD` に保存）。

### シートにないもの

| 情報 | 保存場所 |
| :--- | :--- |
| 管理用パスワード | GAS の「プロジェクトの設定 > スクリプト プロパティ」の `ADMIN_PASSWORD` |
| （任意）別ファイルのスプレッドシートを使う場合の ID | 同じく `SPREADSHEET_ID`（通常は使わない） |
| パスワードの誤入力の回数 | GAS のキャッシュ（10分で消える） |
| 利用者の名前の自動入力・自分の予約・表示の設定 | 利用者のブラウザ（localStorage） |

## 2. 手動でバックアップを取る

おすすめの時期: 年度の切り替えの前後、大きな設定変更の前、担当者の交代の前。（要確認：定期的に取るかどうか・頻度・担当）

### コピーを作成する

1. スプレッドシートを開く。
2. メニュー「ファイル > コピーを作成」を選ぶ。
3. 名前を付ける（例: `練習室予約システム_バックアップ_2026-10-09`）。
4. 保存先に、元と同じ**共有ドライブ**のバックアップ用フォルダを選ぶ（要確認：フォルダ名）。個人の「マイドライブ」には置かないでください。
5. 「コピーを作成」を押す。

- コピーには個人情報（氏名・学籍番号）と、編集用パスワード・限定公開のパスワードなどが含まれます。元のファイルと同じく、管理者以外に共有しないでください。
- コピーされたスプレッドシートは、予約表とはつながっていません（予約表がつながっているのは、元のファイルに紐づいた GAS のデプロイだけです）。コピーで予約を受け付けることはありません。

## 3. 誤って消した・書き換えたときに戻す

### 版の履歴から戻す

Google スプレッドシートは変更の履歴を自動で残しています。

1. スプレッドシートのメニュー「ファイル > 変更履歴 > 変更履歴を表示」を開く。
2. 右側の一覧から、消してしまう前の日時を選ぶ。
3. 内容を確かめて、上部の「この版を復元」を押す。

- **注意: 「この版を復元」をすると、その日時より後の変更（その後に入った予約・取消・操作ログ）もすべて消えます。** 利用者が予約を続けている時間帯に戻すと、他の人の予約まで消えてしまいます。
- 安全に戻すには、次のどちらかにしてください。
  - 少しだけ戻すとき: 変更履歴で消える前の版を開いて必要な行をコピーし、いまのシートに貼り付ける（列の位置をそろえる）。
  - まるごと戻すとき: 先に「ファイル > コピーを作成」でいまの状態を保存してから「この版を復元」し、その後に入った予約を操作ログとコピーを見て入れ直す。
- 戻した後は、予約表を開いて正しく表示されることを確かめてください。

### シートを消してしまったとき

1. まず「変更履歴」から戻せるか確かめる。
2. 戻せない場合は、メニュー「予約システム > 初期セットアップ」を実行すると、見出しだけの空のシートが作り直されます（データは戻りません）。バックアップのコピーからデータを貼り付けてください。

### スプレッドシートのファイルごと消してしまったとき

- 共有ドライブのゴミ箱から戻せます（Google ドライブの左の「共有ドライブ」→ 対象のドライブ → ゴミ箱）。ゴミ箱に残る期間は Google の仕様によります（要確認：現在の保持期間）。
- ゴミ箱を空にした後は戻せません。Google Workspace の管理者に相談してください（要確認：大学の情報システムの窓口）。
- ファイルを戻せなかった場合は、バックアップのコピーを元に、[05_引き継ぎ手順.md](05_引き継ぎ手順.md) の「GAS を新しくデプロイする」と同じ手順で、新しいファイルに GAS を設定し直します（`web/config.js` の URL を書き換えます）。
