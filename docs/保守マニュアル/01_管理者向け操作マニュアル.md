# 01 管理者向け操作マニュアル

対象: 練習室予約システムの管理者（教員・事務・担当学生）。プログラムの知識は不要です。

- 管理画面: https://miyakyo-music.github.io/yoyaku/admin.html （予約表の右上の歯車「管理」からも開けます）
- 管理用パスワードは、責任者の教員またはシステム担当者から受け取ってください（この文書には書きません）。

## 1. ログインとログアウト

1. 予約表の右上の歯車（PC では「管理」）を押す。
2. 「管理者ログイン」の画面で「管理用パスワード」を入れ、「ログイン」を押す。パスキーを登録した端末では、「パスキーでログイン」を押して Face ID・Touch ID などで入れます。
3. 上部に「一般」「休館」「不具合」「利用状況」「設定」のタブが出ます（「設定」の中に、パスワード・パスキー・練習室があります）。
4. 終わったら右上の「ログアウト」を押す。

- ログイン状態は、そのタブ（ブラウザのタブ）を閉じると解除されます。パスキーで入った場合は、12時間たつと入り直しになります。
- **パスキーの登録**: 「設定」タブの「パスキー」で「この端末を登録」を押し、端末の指示に従って Face ID などをします。iCloud キーチェーンなどで同期される場合は、同じアカウントのほかの端末でも使えます。使わなくなった端末や、担当を外れた人のパスキーは「削除」してください。
- 管理用パスワードを全体で10回続けて間違えると、10分間ログインできなくなります（「管理用パスワードの誤入力が続いたため、一時的に利用できません。10分ほど待ってから再度お試しください。」）。10分待ってからやり直してください。
- 保存していない変更があるタブには「●」が付き、「未保存の変更があります」と表示されます。ログアウトするときも確認が出ます。

## 2. 管理者モード（予約表で、どの予約でも変更・取消する）

1. 管理画面にログインした状態で、左上の「‹ 予約表に戻る」を押す。
2. 予約表のタイトルの横に「管理者モード」と表示されます。
3. この状態では、編集用パスワードを知らなくても、どの予約でも「変更」「取消」ができます。予約の詳細に「管理者モード: 編集用パスワードなしで変更・取消できます。」と出ます。
4. 「管理者のみ」の部屋の予約、くり返し予約・複数部屋の同時予約も、管理用パスワードを入れずにできます。限定公開の部屋もすべて表示されます。
5. 終えるときは「管理者モード」を押し、「管理者モードを終了しますか？（管理画面からもログアウトします）」で OK を押す。

- 管理者モードは、管理画面にログインした「同じタブ」でだけ有効です。別のタブや別の端末では管理者モードになりません。
- 管理者モード以外でも、予約の詳細の「編集用パスワード」欄に管理用パスワードを入れると、管理者として変更・取消できます（編集用パスワードを忘れた人の予約を取り消すときなど）。
- 共用のパソコンでは、使い終わったら必ず管理者モードを終了してください。
- 管理者モード中は、歯車の横に、未対応・対応中の不具合報告の件数が数字で表示されます。
- **予約のコピー**: 予約の詳細の「コピー」（スマホでは重なった四角の絵）を押すと、同じ部屋・時間・名前で別の曜日に予約できます。「コピー先」で曜日を選びます（複数可）。くり返し予約とも組み合わせられます。管理者モードのとき（「まとめて予約は管理者のみ」をオフにした場合は全員）だけ使えます。
- **重要な予定の色**: 予約画面の「重要な予定の色」で赤・紫・緑を選ぶと、予約表でその予約が目立ちます。管理者モードか、限定公開の部屋のパスワードを入れたときだけ選べます。

## 3. 「データベース」ボタン（スプレッドシートを開く）

管理画面の上部の「データベース」を押すと、予約台帳・操作ログ・部屋マスタなどが入ったスプレッドシートが開きます。

- 開けるのは、スプレッドシートが共有されている Google アカウントだけです。開けない場合は、スプレッドシートの持ち主に共有を依頼してください（[05_引き継ぎ手順.md](05_引き継ぎ手順.md)）。
- シートの見方は「8. スプレッドシートの見方」と [04_データとバックアップ.md](04_データとバックアップ.md) を見てください。

## 4. 「設定」タブの「練習室」

部屋の追加・削除・名前の変更・並べ替え・予約制限を設定します。変更は「保存」を押すまで反映されません。

### 部屋を追加する

1. 「＋ 部屋を追加」を押す。
2. 「部屋名」（30文字以内）、「特徴タグ」（例: `大・GP`。「・」区切りで複数可。30文字以内）、「設備区分（絞り込み用）」（例: グランドピアノ。20文字以内）、「予約制限」、「備考」（100文字以内）を入れる。
3. 「保存」を押す。「練習室を保存しました」と出れば完了です。

- 同じ部屋名（例: 練習室6）の部屋は、予約するときに「まとめて選択」できます。
- 「設備区分」は、予約表の「すべての設備」の絞り込みに使われます。
- 部屋の内部の番号（部屋ID）は自動で振られ、画面には表示されません。

### 並べ替える

- 左端の番号をつまんで上下にドラッグするか、「↑」「↓」で入れ替えて「保存」。予約表の表示順になります。
- スマホでは各部屋が1行に畳まれています。押すと開いて編集できます。

### 予約制限

| 予約制限 | 意味 |
| :--- | :--- |
| 制限なし | 誰でも予約できる |
| 管理者のみ | 予約・変更・取消に管理用パスワードが必要（教員専用の部屋など） |
| 限定公開 | 限定公開の部屋のパスワードを入れた人だけに表示・予約できる。一般の利用者には部屋があることも表示しない（演習室など）。「6. 限定公開の部屋」参照 |
| 使用停止 | 予約できない（故障・改修中など）。予約表では灰色で表示 |

### 部屋を削除する

1. その部屋の「削除」を押し、確認で OK を押す。
2. 「保存」を押す。

- 今日以降の予約が残っている部屋は削除できません（「『（部屋名）』には今日以降の予約が○件あるため削除できません。先に予約を取り消すか、予約制限を「使用停止」にしてください。」）。その場合は「使用停止」にしてください。

## 5. 「利用時間・制限」タブ

| 項目 | 内容 | 初期値 |
| :--- | :--- | :--- |
| 予約表のタイトル | 画面上部の名前（40文字以内） | 練習室予約 |
| お知らせ | 予約表の上部に表示する連絡（200文字以内。空欄なら表示しない） | 空欄 |
| お知らせの種類 | 「通常（青）」／「重要（赤）」 | 通常 |
| 利用開始時刻／利用終了時刻 | 予約できる時間帯 | 7:00／22:00 |
| 予約単位 | 開始・終了時刻の区切り（1, 2, 3, 4, 5, 6, 10, 12, 15, 20, 30, 60 分） | 5分 |
| 1回の最大予約時間 | 0 = 制限なし。管理者は制限を受けない | 0 |
| 予約受付期間 | 「今日から○日先まで」。0 = 制限なし。管理者は制限を受けない | 0 |
| まとめて予約の最大件数 | くり返し予約・複数部屋の同時予約で1回に登録できる件数（部屋数×日数。1〜300） | 100 |
| 定休日（曜日） | チェックした曜日は予約できない | なし |
| まとめて予約は管理者のみ | チェックすると、くり返し予約・複数部屋の同時予約に管理用パスワードが必要 | チェックあり（はい） |

1. 項目を変えて「保存」を押す。「設定を保存しました」と出れば完了です。
2. 利用者の画面には、次の自動更新（最大1分後）から反映されます。

- 既に入っている予約は自動では取り消されません。新しい利用時間の外にかかる予約や、定休日に入っている予約がある場合は、保存後に件数が表示されます。必要なら個別に取り消してください。
- 利用開始・終了時刻と最大予約時間は、予約単位の区切りにする必要があります（例: 予約単位が15分なら 7:05 は不可）。

### お知らせを出す

1. 「お知らせ」欄に文を入れる（例: 10/22 は入試のため全室利用できません）。
2. 種類を選ぶ。
   - 「通常（青）」: 一般的な連絡
   - 「重要（赤）」: 休館など予約に直結する連絡（赤で目立つ表示になります）
3. 「保存」を押す。
4. お知らせを消すときは、欄を空にして「保存」。

## 6. 限定公開の部屋（演習室など）

一般の学生には見せず、教員・特定の学生だけが使う部屋の設定です。

### 設定する

1. 「設定」タブの「練習室」で、対象の部屋の予約制限を「限定公開」にして「保存」。
2. 「設定」タブの「限定公開の部屋（演習室など）」で、「演習室などのパスワード（6文字以上）」を入れて「保存」。「演習室などのパスワードを保存しました」と出れば完了です。
3. 「入口の URL」の「コピー」を押すと、入口の URL（`https://miyakyo-music.github.io/yoyaku/?limited`）がコピーされます。

### 使う人に伝える

- 使う人に**だけ**、入口の URL とパスワードを伝えてください。掲示や全体向けの連絡には載せないでください。
- 伝える方法: （要確認：個別のメール、授業内での口頭など、学科で決めた方法）
- 使う人は、入口の URL を開いてパスワードを入れます。一度入れた端末では、次からは入力不要です。上部に「限定公開」と表示されている間は、限定公開の部屋が見えます。
- 入口の URL から開くと、設備の絞り込みが限定公開の部屋の設備区分（例: 演習室）に合わせて表示されます。
- 限定公開のパスワードを知っていても、設定の変更や他人の予約の取消はできません（管理用パスワードとは別物です）。
- パスワードが空欄のときは、管理者以外は限定公開の部屋を使えません。

### パスワードが広まったとき

1. 「設定」タブで新しいパスワードに変えて「保存」。
2. 記憶済みの端末でも、次の更新で「限定公開の部屋のパスワードが変更されたため、表示を終了しました。」と出て見えなくなります。
3. 使う人に新しいパスワードを伝え直す。

- 限定公開のパスワードを全体で30回間違えると、10分間受け付けなくなります（総当たり対策）。

## 7. 「休館・利用停止」タブ

入試・調律・清掃などで予約を受け付けない日時を登録します。追加・削除はすぐに保存されます。

### 登録する

1. 「追加」の欄で「日付」を選ぶ。
2. 「対象」で「全室」または部屋を選ぶ。
3. 終日なら「終日」にチェック。時間帯だけなら「終日」を外して「時間帯」を選ぶ。
4. 「理由」を入れる（例: ピアノ調律。50文字以内）。
5. 「追加」を押す。「追加しました」と出れば完了です。

- 予約表では、その時間帯が灰色の斜線で表示され、理由が出ます。その時間帯は予約できません。
- 既に入っている予約は自動では取り消されません。重なる予約がある場合は「休館・利用停止と重なる予約が○件あります（自動では取り消されません）:」と一覧が出ます。必要なら予約者に連絡のうえ、管理者モードで取り消してください。
- 毎週決まった曜日が休みのときは、「利用時間・制限」タブの「定休日」を使います。

### 削除する

1. 「登録済み」の一覧で「削除」を押し、確認で OK を押す。
2. 過去の登録を見るときは「過去の分も表示」にチェックします。

## 8. 「設定」タブ

| 項目 | 内容 |
| :--- | :--- |
| 限定公開の部屋（演習室など） | 「6. 限定公開の部屋」参照 |
| 予約表全体の閲覧制限（通常は使いません） | 設定すると、利用者全員が予約表を開くときにパスワードの入力を求められる（利用者の端末に記憶される）。学外に予約表を見せたくない場合などに使い、利用者全員に伝える。空欄なら誰でも閲覧・予約できる |
| 管理用パスワードの変更 | 「新しいパスワード（6文字以上）」と「新しいパスワード（確認）」を入れて「変更する」。担当者の交代時などに変更する |

- 管理用パスワードを変えると、他の端末・タブの管理者モードは「管理者モードを終了しました（管理用パスワードが変更された可能性があります）。」と出て終了します。
- パスワードの「表示」ボタンで、入力中の文字を確かめられます。

## 9. 「不具合報告」タブ

利用者が予約表の「不具合を報告」から送った内容が、新しい順に表示されます（最大200件）。

1. 「不具合報告」タブを開く。タブの数字は、未対応・対応中の件数です。
2. 内容・連絡先・受付日時を確認する。「端末・環境の詳細」を開くと、送信時の版・端末・画面の大きさ・表示していた画面・直近のエラーなどが見られます。
3. 状態を選ぶと、すぐに保存されます（「状態を変更しました」）。

| 状態 | 使い方 |
| :--- | :--- |
| 未対応 | 届いたばかり（初期値） |
| 対応中 | 確認・修正を進めている |
| 対応済み | 直した・回答した |
| 対応しない | 仕様どおり・再現しない・いたずら など |

- 「対応済み」「対応しない」は普段は隠れています。「対応済みも表示」にチェックすると表示されます。
- 「再読み込み」で最新の報告を取り直します。
- 連絡先が書かれていて返信が必要な場合は、管理者から直接連絡してください。
- 報告はスプレッドシートの「不具合報告」シートにも記録されています。

## 10. スプレッドシート（データベース）の見方

管理画面の「データベース」から開きます。詳しい列の説明は [04_データとバックアップ.md](04_データとバックアップ.md) にあります。

| シート | 中身 | 直接編集してよいか |
| :--- | :--- | :--- |
| 予約台帳 | 予約1件 = 1行 | いたずら予約の行を削除する程度なら可。列の順番・1行目の見出しは変えない |
| 部屋マスタ | 部屋の一覧と予約制限 | 管理画面で操作するのが安全。部屋IDは変えない |
| 休館・利用停止 | 休館の登録 | 可（管理画面と同じ結果になる） |
| 設定 | 利用時間・お知らせ・パスワード類 | 可。A列（項目名）は変えない |
| 操作ログ | 予約・変更・取消・設定変更の記録 | 見るだけにする |
| 不具合報告 | 利用者からの報告 | 見るだけにする（状態は管理画面で変える） |
| 予約台帳_YYYY年度 | 前年度の予約（年度切り替えで作られる） | 見るだけにする |

- シート名と1行目の見出しは変えないでください。変えると予約表が動かなくなります。
- 予約を取り消すと「予約台帳」からは消えますが、「操作ログ」に「取消」として誰の予約をいつ消したかが残ります。「誰が予約を消したか知りたい」ときは操作ログを見てください。
- 手入力するときは、先頭に `=` `+` `-` `@` を付けないでください。

## 11. 年度の切り替え（毎年4月の最初の週）

1. スプレッドシートのメニュー「予約システム > 前年度の予約をアーカイブ」を選ぶ。
2. 「（日付） より前の予約を『予約台帳_YYYY年度』シートへ移動します。よろしいですか？」で OK を押す。
3. 移動した件数が表示されます。4月1日以降の予約は「予約台帳」に残ります。

## 12. よくある対応

| 状況 | 対応 |
| :--- | :--- |
| 編集用パスワードを忘れた人がいる | 管理者モードで変更・取消する（または編集用パスワード欄に管理用パスワードを入れる） |
| 編集用パスワードを5回間違えてロックされた | 10分待てば再び操作できる。急ぐ場合は管理者モードで対応 |
| 端末を替えた・ブラウザのデータを消したので「自分の予約」に出ない | 予約自体は残っている。編集用パスワードがあれば本人が変更・取消できる。なければ管理者が対応 |
| 1人が長時間押さえすぎる | 「利用時間・制限」で最大予約時間・予約受付期間を設定 |
| 授業で毎週予約したい | 管理者モードでくり返し予約する（「くり返し予約する」→毎週／隔週／毎日→最終日） |
| 授業の予約を学期の途中で終える | 消したい最初の日の予約を開き、「同じまとめ予約のうち、この日以降の分（全部屋）をまとめて取り消す」にチェックして「取消」 |
| いたずら予約がある | 管理者モードで取り消す（操作ログに残る） |
