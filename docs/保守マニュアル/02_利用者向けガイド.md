# 02 利用者向けガイド（練習室の予約のしかた）

対象: 練習室を使う学生・教員。掲示や配布にそのまま使えます。

**予約表: https://miyakyo-music.github.io/yoyaku/**

登録やアプリのインストールは不要です。スマホ・パソコンのブラウザで開いてください。ホーム画面やブックマークに追加しておくと便利です。

## 予約表の見方

- 上の「一覧」「部屋別」「カレンダー」で表示を切り替えます。
  - 「一覧」: その日の全部屋。部屋名を押すと、その部屋の「部屋別」に移ります
  - 「部屋別」: 1つの部屋の予約を、選んだ日から1か月分、日ごとに表示。日付を押すと、その日の「一覧」に移ります
  - 「カレンダー」: 月ごとの表示。日付を押すと、その日の「一覧」に移ります
- 「‹」「›」で前日・翌日、「今日」で今日に戻ります。
- 色の意味: 「予約済み」／「この端末の予約」（この端末で予約したもの）／「利用不可」（休館・定休日など。灰色）
- 赤い線は今の時刻、灰色の部分は過ぎた時間です。
- 予約表は1分ごとに自動で最新になります。すぐ確かめたいときは、タイトルの横の「○:○○ 更新」を押してください。

## 予約する

### パソコン

1. 空いている所をクリックする（その位置から1時間の予約画面が開きます）。時間を決めて選ぶときは、空いている所をドラッグします。
2. 予約画面で内容を確かめて入力し、「予約確定」を押す。

### スマホ

1. 空いている所を1回タップすると、「＋予約」の帯が出ます。
2. その帯をもう一度タップすると、予約画面が開きます（「＋予約」は5秒ほど押さないと消えます）。
3. 時間を指で決めたいときは、空いている所を**長押し**してから、指を横になぞります。
4. 予約画面で入力して「予約確定」を押す。

- 上の「＋予約」（パソコンでは「＋ 新規予約」）からも、部屋・日付・時刻を選んで予約できます。
- スクロールの途中や直後のタップは、予約の操作になりません。

### 予約画面で入力すること

| 欄 | 入力 |
| :--- | :--- |
| 氏名／団体名 | 必須（50文字以内）。例: 宮教太郎／宮教オケ |
| 学籍番号／所属（任意） | 30文字以内。例: G8032／教員 |
| 備考（任意） | 100文字以内。例: 伴奏合わせ |
| 編集用パスワード（任意・4桁の数字） | 後で変更・取消するときに使う4桁の数字 |

- **編集用パスワードを設定しない予約は、誰でも変更・取消できます。** 設定をおすすめします。
- 予約表は誰でも見られます。氏名・学籍番号／所属は他の人にも表示されます。表示されて困る情報は入力しないでください。
- 2回目からは、氏名・学籍番号・編集用パスワードが自動で入ります（その端末のブラウザに記憶。サーバーには送りません）。

## 変更する・取り消す

1. 予約表で自分の予約を押す。「予約の詳細」が開きます。
2. 「編集用パスワード（予約時に設定した4桁）」を入れる（設定していない予約は不要）。
3. 「変更」を押して日付・部屋・時間・氏名・備考を直し「変更を保存」、または「取消」を押して確認で OK。

- 終了した予約は変更できません。
- 編集用パスワードを5回続けて間違えると、その予約は10分間操作できなくなります。
- 編集用パスワードを忘れたときは、管理者に連絡してください。

## 自分の予約を見る

- 上の「自分の予約」を押すと、この端末で作った今日以降の予約が一覧で出ます。押すとその日の予約表に移ります。
- 別の端末で作った予約や、ブラウザのデータを消した後は表示されません（予約自体は残っています）。

## 今すぐ使える部屋を探す（空室）

- 「一覧」で「空室」を押すと、今から30分以上空いている部屋だけが「○時まで空き」と添えて表示されます。
- もう一度押すと元の表示に戻ります。

## 表示を見やすくする

- 指2本で広げる・縮める（パソコンは Ctrl を押しながらホイール、またはトラックパッドのピンチ）と、時間の目盛りの幅が変わります。
- 元に戻すときは、予約表の左上の「幅をリセット」を押します。
- 「すべての設備」の欄で、ピアノの種類などで部屋を絞り込めます。

## ホーム画面に追加する（アプリのように使う）

- iPhone: Safari で予約表を開き、共有ボタン（□に↑）→「ホーム画面に追加」。
- Android: Chrome で予約表を開き、右上の︙ →「ホーム画面に追加」（または「アプリをインストール」）。
- ホーム画面のアイコンから開くと、全画面で使えます。電波が弱い場所でも、最後に見た予約表が出ます。

## カレンダーに入れる

予約の詳細（自分の予約の帯を押す）の右上の「カレンダーに追加」を押すと、iPhone は標準のカレンダー、Android は Google カレンダーに入ります。開始15分前に知らせが出ます（iPhone）。

## 困ったとき

- 「すでに存在する予約と時間が重複しています」: その時間は他の人が先に予約しました。予約表が最新になるので、空いている時間を選び直してください。
- 「過去の時間帯は予約できません」「定休日（○曜日）のため予約できません」「○○ は利用できません（理由）」: その日時は予約できません。
- 画面の下に「システムが更新されました。ページを再読み込みしてください。」と出たら、「再読み込み」を押してください。
- 不具合や使いにくい点は、予約表の下（試験運用中は上の帯にも）の「不具合を報告」から送ってください。
- 個人情報の扱いは「プライバシーポリシー」（予約表の下のリンク）を見てください。
