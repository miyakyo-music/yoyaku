# デザイン統一メモ（作業ブランチ: design-unify）

予約の帯を iOS のカレンダー風（控えめなガラス）にしたので、ほかの部品も iOS 風にそろえていく。
このブランチで作業し、確認できたら main に取り込んで公開する（main に push すると自動で公開される）。

## 方針（2026-10-09 に提案・合意したもの）

| 部品 | 今 | そろえる形 |
| :--- | :--- | :--- |
| 表示の切り替え（一覧／部屋別／カレンダー） | 枠線で囲んだボタンの列 | iOS のセグメント（灰色の溝の中で白いつまみが選択中を示す） |
| ボタン | 灰色の枠線 | 枠線なしの薄い灰色の面。青で塗るのは主役（＋予約）だけ。「今日」などは青い文字だけ |
| 入力欄 | 灰色の枠線 | 枠線なしの灰色の面（#f2f2f7 程度） |
| 予約画面などのダイアログ | 下に「戻る」「予約確定」 | iOS のシート風。上端の左に「キャンセル」、右に確定ボタン |
| 管理画面・プライバシーポリシー | 個別のデザイン | 同じルールで作り直す |

## 共通ルール

- 角の丸み: ボタン 9px ／ 入力欄 10px ／ カード・ダイアログ 14px ／ 予約の帯 9px
- 影: 浮いている物（予約の帯・詳細カード・ダイアログ）だけに付ける
- 青（#007aff 系）: 「押す主役」と「この端末の予約」だけ。オレンジ（#ff9500 系）は「予約済み」
- 文字: system-ui（iPhone では SF Pro）。太さは 400 と 600 を基本に
- ライトモードのみ（ダークモードにはしない）

## 進め方

1. まず予約表の上部（ヘッダ）だけを作り、実際の表示で確認する
2. 予約画面・詳細画面などのダイアログ
3. 管理画面・プライバシーポリシー

各色・角丸は web/index.html の :root の変数にまとめ、管理画面でも同じ値を使う。

## 具体的な作業計画（次回以降）

### 0. 下準備（30分）
- `web/index.html` の `:root` に、部品用の変数を足す（今の `--accent` などは残し、段階的に置き換える）
  - 面: `--fill`（ボタン・入力欄の灰色の面 #e9e9ee）、`--fill-field`（入力欄 #f2f2f7）
  - 角丸: `--r-btn: 9px` `--r-field: 10px` `--r-card: 14px` `--r-blk: 9px`
  - 影: `--shadow-float`（詳細カード・ダイアログ用）
  - 青: `--accent` を #007aff 系に寄せるか検討（今は #2563eb。予約の帯の青 #007aff と揃っていない）
- 管理画面 `web/admin.html` は同じ変数を持つので、同じ値に書き換えるだけで追従するようにしておく

### 1. ヘッダ（予約表の上部）
- 対象: `.btn` `.seg` `.tabs` `.datenav` `.selects select` `.free-btn` `.date-display` `.admin-link`
- 表示の切り替え: `.seg` を iOS のセグメント（灰色の溝 + 白いつまみ）に。「空室」の選択中の緑は色を残すか要相談
- ボタン: 枠線をやめて `--fill` の面に。「＋予約」だけ青。「今日」は青い文字のみ
- 確認すること: スマホ 360/375/480px、PC 1280px で横にはみ出さない／iPhone で選択欄を押しても拡大されない

### 2. ダイアログ（予約・詳細・自分の予約・不具合報告・パスワード入力）
- 共通: 角丸 14px、上端に見出し、`.actions` のボタンを iOS のシート風に（左上「キャンセル」、右上に確定）するかは、
  スマホで親指が届く位置（下）とのトレードオフがあるので、実物で比べてから決める
- 入力欄: 枠線なしの `--fill-field` の面。フォーカス時だけ青い枠
- 予約の詳細画面の `.summary` は、詳細カード（PC のマウスオーバー）と同じ見た目のまま
- 注意: iOS 15.3 以前向けの代替ダイアログ（`body.dialog-fallback`）でも崩れないか確認

### 3. 管理画面・プライバシーポリシー
- 管理画面のタブ・カード・ボタン・入力欄を同じルールに。部屋の一覧（スマホで畳む表示）は今の構成のまま見た目だけ
- プライバシーポリシーは見出しとカードの角丸・色だけ

### 4. 仕上げ
- フッタ・試験運用中の帯・お知らせの帯の色と角丸を見直す
- 版を上げる（例: v0.4.0-beta）

### 確認の進め方
- 各段階でテスト環境（`python3 dev/serve.py`）の画面を送って確認をもらい、OK が出た段階ごとに main に取り込んで公開する
- 本番の見た目を一気に変えないよう、1 → 2 → 3 の順で公開する
