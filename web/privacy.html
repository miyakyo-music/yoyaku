プライバシーポリシー

宮教大音楽棟 練習室予約（以下「本システム」）で扱う情報とその取り扱いについて説明します。本システムは、音楽棟の練習室を管理する担当者（以下「管理者」）が運用しています。

1. 取得する情報

予約時氏名または団体名、学籍番号または所属（任意）、備考（任意）、編集用パスワード（任意）、予約した部屋・日時
変更・取消時操作内容と日時（操作ログとして記録）
不具合報告時報告内容、連絡先（任意）、端末・ブラウザの種類、画面サイズ、表示中の画面、直近のエラー内容

※アクセス解析や広告目的の情報収集（Cookieによる追跡など）は行っていません。

2. 利用目的

  • 練習室の予約受付および予約表への表示
  • 利用者自身による予約履歴・練習時間の確認
  • 重複予約の防止、および予約者本人による変更・取消の認証
  • いたずらや誤操作発生時の経緯確認（操作ログ）
  • システムの不具合修正および利便性向上（不具合報告）

取得した情報は、上記以外の目的には使用しません。

3. 公開範囲

予約表は、URLを知っている人なら誰でも閲覧できます。予約した部屋・時間とともに、氏名（団体名）および学籍番号（所属）が他の利用者にも表示されます（備考は予約の詳細画面に表示されます）。また、「自分の予約」内の「名前で探す」機能では、誰でも氏名・団体名や学籍番号・所属から、対象者の過去の予約履歴や練習時間の集計（よく使う部屋や曜日など）を検索・閲覧できます。公開されて困る情報は入力しないでください。

  • 編集用パスワード：画面には表示されず、管理者のみが確認できます。
  • 操作ログ・不具合報告：管理者のみが閲覧できます。
  • 限定公開の部屋（演習室など）の予約：該当室のパスワードを知っている利用者と管理者のみに表示されます。

4. 保管場所と期間

  • データベース：予約・操作ログ・不具合報告は、Cloudflare（米国 Cloudflare, Inc.）のサーバーに保管し、バックアップおよび閲覧用として大学の Google Workspace 上のスプレッドシートに複製を保存しています（保管先をスプレッドシートに切り替えた場合は、Google Apps Script 経由でスプレッドシートに直接読み書きします）。
  • キャッシュ（高速化用の複製）：表示高速化のため、公開用の予約データ（部屋・日時・氏名／団体名・学籍番号／所属・備考）の複製を Cloudflare（アジア太平洋地域）のサーバーに配置しています。この複製に編集用パスワードや限定公開部屋の予約は含まれません。予約更新のたびに上書きされ、先月より前のデータは消去されます。
  • 管理者用パスキー：管理者のパスキーログイン用として、管理者の端末の公開鍵と登録名を Cloudflare に保管します（一般利用者の情報は含まれません）。
  • 配信サーバーのログ：画面配信には GitHub Pages、データ通信には Cloudflare を利用しています。各事業者は配信に伴い接続元のIPアドレス等を記録する場合があります（詳細は GitHub のプライバシーステートメント および Cloudflare のプライバシーポリシー を参照してください）。
  • 保管期間：取り消された予約は予約表から消去されますが、操作ログには記録が残ります。前年度の予約データは毎年度初めに予約表から外し、記録用の別シートへ移行します。予約・操作ログ・不具合報告は、運用上不要になったと管理者が判断した時点で削除します。

5. 安全管理措置

情報の漏洩や改ざんを防ぐため、以下の対策を実施しています。

  • 通信の暗号化：画面とサーバー間の通信はすべて暗号化（HTTPS）しています。
  • パスワードの非送信：サーバーからの応答データに編集用パスワード自体は含めず、パスワード設定の有無のみを画面に返します。
  • 連続誤入力の制限：パスワードを連続して間違えると、約10分間操作を制限します（編集用は5回、管理用は10回。限定公開用・閲覧用パスワードも同様です。一括予約に対する試行は合算してカウントします）。
  • 連続操作の制限：いたずらによる予約枠の埋め尽くしを防ぐため、短時間に集中した予約操作は一時的に制限します。
  • 管理画面の保護：管理画面は、管理用パスワードまたは登録済みパスキーで認証した管理者のみがアクセスできます。
  • 無害化処理：入力された氏名や備考は単なる文字列として処理し、プログラム（スクリプト）やスプレッドシートの計算式として実行されないよう対策しています。

6. 端末（ブラウザ）に保存する情報

入力の手間を省くため、お使いのブラウザ（localStorage）に以下の情報を保存します。これらはその端末・ブラウザ内でのみ利用されます。なお、パスワード類と「自分の予約」の一覧は照合・表示のためにサーバーへ送信されますが、サーバー側には保存されません。

  • 前回入力した氏名・学籍番号・編集用パスワード（自動入力用）
  • その端末で作成した予約の一覧（「自分の予約」表示用）
  • 「自分の予約」の検索方法、および「名前で探す」の最終検索キーワード
  • 表示設定（一覧・部屋別・カレンダーの切り替え、設備フィルタ、時間軸の幅など）
  • 入力済みの閲覧パスワード・限定公開部屋のパスワード
  • 前回表示した予約表データ（次回起動時の高速表示用。限定公開部屋や管理者用の表示は保存しません）
  • 管理者ログイン済み端末の識別情報（管理者の端末のみ。サーバー側にも保管し、他者の誤入力によるロックアウトから保護するために使用します）

※共用端末を利用した場合は、ブラウザの「閲覧履歴・サイトデータの削除」からこれらの情報を消去できます。

7. 第三者への提供

法令に基づく場合を除き、取得した情報を本人の同意なく第三者に提供することはありません。

8. 削除・訂正の依頼、お問い合わせ

ご自身の予約は、予約表から直接変更・取消が可能です。それ以外のデータの削除・訂正依頼やお問い合わせは、予約表下部の「不具合を報告」または管理者へ直接ご連絡ください。

9. ポリシーの変更

システムの機能変更等に伴い、本ページを更新することがあります。重要な変更がある場合は、予約表のお知らせ欄で告知します。
