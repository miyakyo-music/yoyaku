プライバシーポリシー

宮教大音楽棟 練習室予約（以下「本システム」）で扱う情報と、その取り扱いについて説明します。本システムは、音楽棟の練習室を管理する担当者（以下「管理者」）が運用しています。

1. 集める情報

予約のとき氏名または団体名、学籍番号または所属（任意）、備考（任意）、編集用パスワード（任意）、予約した部屋・日時
予約の変更・取消のとき操作の内容と日時（「操作ログ」として記録します）
不具合を報告するとき報告の内容、連絡先（任意）、端末・ブラウザの種類、画面の大きさ、表示していた画面、直近に表示されたエラー

本システムは、利用状況の分析や広告のための情報（アクセス解析・Cookie による追跡など）は集めていません。

2. 使う目的

  • 練習室の予約を受け付け、予約表に表示するため
  • 予約の重複を防ぎ、予約者本人による変更・取消を確かめるため
  • いたずらや誤操作があったときに、経緯を確かめるため（操作ログ）
  • 不具合を直し、使いやすくするため（不具合報告）

これ以外の目的には使いません。

3. 誰に見えるか

予約表は、本システムの URL を知っている人なら誰でも見られます。予約した部屋・時間とあわせて、氏名または団体名、学籍番号または所属が、他の利用者にも表示されます。備考は、予約を押したときの詳細に表示されます。表示されて困る情報は入力しないでください。

  • 編集用パスワードは画面には表示せず、管理者以外は見られません。
  • 操作ログ・不具合報告は、管理者だけが見られます。
  • 限定公開の部屋（演習室など）の予約は、その部屋のパスワードを知っている人と管理者にだけ表示されます。

4. 保管する場所と期間

  • 予約・操作ログ・不具合報告は、大学の Google Workspace 上のスプレッドシートに保管し、Google Apps Script を通して読み書きします。
  • 予約表の画面は GitHub Pages から配信しています。GitHub は、ページを配信するために接続元の IP アドレスなどを記録することがあります（GitHub のプライバシーステートメント）。
  • 取り消された予約は予約表から消えますが、操作ログには記録が残ります。
  • 前年度の予約は、毎年度の初めに予約表から外し、記録用の別シートに移して保管します。予約・操作ログ・不具合報告は、運用に必要なくなったと管理者が判断した時点で削除します。

5. お使いの端末に保存する情報

入力の手間を省くため、次の情報をお使いのブラウザの中（localStorage）に保存します。これらはサーバーには送られず、その端末・ブラウザでだけ使われます。

  • 前回入力した氏名・学籍番号・編集用パスワード（次回の自動入力用）
  • この端末で作った予約の一覧（「自分の予約」の表示用）
  • 表示の設定（一覧・部屋別・カレンダー、設備の絞り込み、時間軸の幅など）
  • 入力したパスワード（閲覧パスワード・限定公開の部屋のパスワード）

共用の端末で使った場合は、ブラウザの「履歴・サイトデータの削除」でこれらを消せます。

6. 第三者への提供

法令に基づく場合を除き、集めた情報を本人の同意なく第三者に提供しません。

7. 削除・訂正の依頼、問い合わせ

自分の予約は、予約表から変更・取消できます。それ以外の削除・訂正の依頼や問い合わせは、予約表の「不具合を報告」から、または管理者に直接ご連絡ください。

8. このポリシーの変更

本システムの機能を変えたときなどに、このページを更新することがあります。大きな変更は予約表のお知らせでお知らせします。
